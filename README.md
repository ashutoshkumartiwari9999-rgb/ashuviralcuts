# Ashuviralcuts 🎮

**Free viral clip engine for GTA 6 clippers and content creators.**

Paste any YouTube/Twitch/Kick stream link → get captioned 9:16 clips in minutes.

## Features
- ⚡ AI-powered highlight detection
- 🎬 Auto-captioned vertical clips (9:16 for Shorts/Reels/TikTok)
- 🤖 AI Hook generator
- 🎮 GTA Neon caption style
- 📱 Works on any device (phone, PC, tablet)

## Deploy on Render (Free)
1. Fork this repo on GitHub
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect your GitHub repo
4. Render auto-detects `render.yaml` and deploys

## Local Setup
```bash
pip install -r requirements.txt
python app.py
```
Then open http://127.0.0.1:8770
